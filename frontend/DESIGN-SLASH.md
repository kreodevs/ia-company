# Slash — Style Reference (Dark theme)

> Midnight vault with gilded ledger lines.

**Theme id:** `slash` · **Mode:** dark

See the full Slash specification in the project design brief. Implementation:

- Tokens: `src/styles/slash-theme.css`
- Display serif: Libre Caslon Display (`--font-display`, Ivy Presto substitute)
- UI sans: Inter (`--font-sans`)
- Primary action: white pill on black text
- Accent: copper `#cc9166` (categories, links, charts)
- Radii: 9999px pills, 10px cards, 2px nav
- Canvas: obsidian `#08080a`

## Gilded gradient

Chart accent token: `--gradient-gilded-gradient` (reserved for data viz, not general UI).
