# Org OS components

Kreo-compatible UI for departments (Org Units).

| Component | Role |
|-----------|------|
| `SchemaDynamicForm.tsx` | Renders `configSchema` JSON (Kreo DynamicForm field contract). Swap for pulled `DynamicForm` when Kreo DEV bootstrap completes. |
| `ArtifactGallery.tsx` | Table of typed deliverables (`copy`, `social_post`, `design`, …). |

See [ADR-org-os](../../../docs/cto/ADR-org-os.md).
