# Catalog Studio components

UI for LLM-assisted agent/skill proposals with human approval gates.

| Component | Role |
|-----------|------|
| `CatalogStudioSkillPanel` | Brief → propose → Munger → approve checkbox → apply |
| `CatalogStudioAgentPanel` | Same + per-new-skill approval checkboxes |
| `MungerReviewPanel` | Shared Munger pre-mortem display |

Used from `pages/ai-team/AiTeamHubPage.tsx` tabs **Crear agente** / **Crear habilidad**.
