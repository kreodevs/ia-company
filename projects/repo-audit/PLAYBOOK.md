# Repo Audit — operator playbook

1. **Apply vertical pack** from Products → Vertical packs.
2. **Configure GitHub** — Settings → Integrations (token for private repos).
3. **Commission audit** — Office → Ingeniería → *Repo analysis* with `https://github.com/org/repo` in the brief.
4. **Deliver findings** — encargo detail → delivery wizard → client link.
5. **Record revenue** — encargo detail → Revenue when the audit fee is collected.

## Upsell path

After delivery, offer a **feature-development** remediation sprint using the same product workspace under `projects/repo-audit/`.

## Quality checklist

- [ ] GitHub URL in encargo request
- [ ] ADR or architecture section in docs/cto/
- [ ] Prioritized findings (P0/P1/P2)
- [ ] Client-facing executive summary in final report
